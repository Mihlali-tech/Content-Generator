# AI Content Generator 🤖

A simple, user-friendly web tool that helps users create different types of content using AI-inspired prompts. Users can choose between **Text, Image, and Code**, enter their own prompt, or select a ready-made prompt from the built-in prompt library.

## ✨ Features

* 📝 **Text Generation** – Create drafts for social media, emails, marketing content, and blog posts.
* 🖼️ **Image Generation Prompts** – Create detailed prompts for AI image generation.
* 💻 **Code Generation** – Generate code drafts based on a user's requirements.
* 📚 **Prompt Library** – Ready-to-use prompts organized into:

  * Social Media
  * Email
  * Marketing
  * Blog Writing
  * Images
  * Coding
* 🔄 **Generate Again** – Quickly create another output from the same prompt.
* 📋 **Copy Output** – Copy generated content to the clipboard.
* 🗑️ **Clear** – Reset the prompt and output.
* 📱 **Responsive Design** – Works across desktop and mobile screen sizes.
* 🎨 **Clean Interface** – Designed to be simple and beginner-friendly.

## 💡 How to Use

1. Open the AI Content Generator.
2. Select a content type:

   * Text
   * Image
   * Code
3. Enter a prompt into the prompt box.
4. Alternatively, select a prompt from the **Prompt Library**.
5. Edit the prompt if necessary.
6. Click **Generate**.
7. Review the generated output.
8. Use **Copy** to copy the result or **Generate Again** to create another version.

## 📚 Example Prompts

### Social Media

> Create an engaging Instagram caption promoting [product/service] for [target audience].

### Email

> Write a professional email to [recipient] about [topic]. Keep the tone friendly and professional.

### Marketing

> Create a short marketing message promoting [product] and highlight its main benefits.

### Blog

> Write a 500-word blog post about [topic] for [target audience]. Use a clear and engaging tone.

### Image

> Create an image of [subject] in [style]. Include [specific details].

### Coding

> Write [programming language] code that [describe what the code should do]. Explain the code briefly.

## ⚙️ Current Version

This project is currently a **frontend prototype**. The interface and content-generation workflow are fully implemented using HTML, CSS, and JavaScript.

The current version provides demonstration outputs and image-generation prompts. A future version can connect to a real AI API to generate live text, images, and code.
